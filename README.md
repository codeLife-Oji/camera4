# カメラ4択

カメラに映した4択問題を AI（Claude）が読み、正解の選択肢を映像の上に枠で示すページです。
練習問題・自分の教材で使うためのものです。

- 使うには Claude の API キーが要ります。キーは開いたブラウザの中にだけ保存され、このページには入っていません。
- 読み取りの費用はキーの持ち主に請求されます。月の上限（円の目安）を画面で決められます。
- `anthropic.js` は Anthropic の TypeScript SDK（@anthropic-ai/sdk 1.10.0）を1ファイルにまとめたものです（MIT、LICENSE-anthropic-sdk.txt）。
